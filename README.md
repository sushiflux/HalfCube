# Partcraft

**[English](#english) · [Deutsch](#deutsch)**

## English

Partcraft will be an open-source, parametric 3D CAD program. You sketch in 2D first, with constraints and dimensions, and build solid bodies from those sketches.

- Every step is recorded in a timeline. You can go back and change any step later.
- Parts can be turned into components and joined into assemblies.
- Exchange with other programs works through common formats such as STEP, STL and 3MF.

### Platforms

Windows comes first, then Linux. A browser version is planned from the start. macOS follows later.

### Status

Partcraft is in early development. The first scaffold (user interface shell, engine with geometry kernel and sketch solver, message protocol) is being built; there is no usable version and no download yet.

## Deutsch

Partcraft wird ein quelloffenes, parametrisches 3D-CAD-Programm. Man skizziert zuerst in 2D, mit Bedingungen und Maßen, und baut aus den Skizzen Volumenkörper.

- Alle Schritte stehen in einer Zeitleiste. Man kann sie später jederzeit ändern.
- Bauteile lassen sich als Komponenten zu Baugruppen verbinden.
- Der Austausch mit anderen Programmen läuft über gängige Formate wie STEP, STL und 3MF.

### Plattformen

Zuerst kommt Windows, dann Linux. Eine Browser-Version ist von Anfang an geplant. macOS folgt später.

### Status

Partcraft ist in früher Entwicklung. Das erste Grundgerüst (Oberflächenrahmen, Engine mit Geometriekern und Skizzen-Solver, Nachrichtenprotokoll) entsteht gerade; es gibt noch keinen nutzbaren Stand und keinen Download.
